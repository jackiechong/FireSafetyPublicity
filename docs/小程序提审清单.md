# 葫芦岛消防培训小程序提审清单

## 一、代码侧已补齐

- 小程序内已增加《隐私政策与用户协议》页面：`pages/privacy/privacy`。
- 登录页已提供协议入口。
- 实名登记页已增加“已阅读并同意”确认，未勾选时不能提交姓名、手机号、单位、职务等信息。
- `app.json` 已开启 `__usePrivacyCheck__`。
- `project.config.json` 已开启合法域名校验，便于上传前在开发者工具中提前发现域名配置问题。

## 二、微信公众平台必须确认

- 小程序 AppID 与 `miniprogram/project.config.json` 中的 `appid` 一致。
- 服务器域名中已配置 request 合法域名：`https://hld-xfpx.xyz`。
- 域名 HTTPS 证书有效，域名已备案，且备案主体与小程序主体关系符合微信要求。
- “服务内容声明 / 用户隐私保护指引”已填写并提交，通过后再提审版本。
- 隐私指引中至少声明会处理以下信息：微信 openid、姓名、手机号、所属区县、所在单位、职务/岗位、培训签到记录、培训时长。
- 服务类目应与实际用途一致，建议选择与政务民生、消防培训、行业培训或单位内部培训管理相匹配的可用类目。

## 三、线上后端必须确认

- 生产环境已配置 `WECHAT_APPID` 和 `WECHAT_SECRET`，不能使用开发桩 openid。
- `SECRET_KEY` 已替换为随机长字符串，不能使用默认值。
- `https://hld-xfpx.xyz/health` 可访问，并返回 `status: ok`。
- 小程序端所有接口都走 HTTPS 域名，不使用 localhost、127.0.0.1 或内网地址。
- 数据库已准备正式数据，测试种子数据不会出现在审核可见页面中。

## 四、建议提交审核时填写的测试说明

审核说明可写：

本小程序用于葫芦岛市消防培训实名登记、现场签到、培训记录查询和授权管理员移动创建培训。审核人员可点击“微信登录”，首次进入后按页面提示填写姓名、手机号、区县、单位和职务完成实名登记，再进入“我的”查看个人信息和培训记录。管理员功能需由后台生成绑定码后使用，仅面向授权工作人员。

若需要审核管理员功能，请在提交审核前准备一个 8 位有效绑定码，并在审核说明中补充：

管理员测试绑定码：请填写实际后台生成的 8 位绑定码，有效期内提交审核。

## 五、提审前自测路径

1. 微信开发者工具导入 `miniprogram` 目录。
2. 确认详情中不再勾选“不校验合法域名”。
3. 点击“微信登录”，确认能完成登录。
4. 首次实名登记时，不勾选协议应无法提交；勾选后可提交。
5. 进入“我的”，确认个人信息、学习专栏、培训记录能正常加载。
6. 点击“加入培训”，确认无开放培训时提示清晰，有开放培训时可完成签到。
7. 使用有效管理员绑定码测试管理员绑定、创建培训、查看二维码信息。
